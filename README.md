# WAP Probe

WAP Probe 是一个用于传统 WAP 协议研究、WML/WMLC 解析、HTTP 证据采集、离线回放和互操作验证的 Python 工程。

## 项目状态

当前研发基线为 **R5**，正在推进 **R6** 多站点发现和端到端验证。

| 阶段 | 主题 | 状态 |
| --- | --- | --- |
| R5 | 协议研究、WML/WMLC 解析与证据采集基线 | 当前基线 |
| R6 | 多站点发现与端到端验证 | 进行中 |

## 研发原则

- 只使用公开、无需登录的测试目标。
- 网络采集限制为安全的 GET 请求。
- HTTP 与 HTTPS 分开验证，不自动跟随重定向。
- 保留原始响应、SHA-256 和可复核的测试证据。
- 区分直接原站响应、网关转换结果和原生 WAP 测试。
- 未经实际执行和验收，不得宣称 A-origin 或 A-navigation 通过。
